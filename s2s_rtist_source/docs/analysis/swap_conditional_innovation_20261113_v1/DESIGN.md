# 条件创新量：先扣除 C 可预测的水分残差

2026-11-13，真实计算前冻结。唯一主候选 on。核心问题仍是成熟单动作水分 W 是否能在原专家合法 C 之外改善后续灌溉净收益排序。旧 model-matched 候选已关闭，不重跑、调参或改变其结论。

本轮检验的具体假设：直接用原始探针残差训练修正，可能让水反馈头承担可由合法上下文解释的系统误差；将这部分交给 C-only 基线后，来源时间留出的剩余创新能否提供可迁移的增量。这是假设，不是已确认的失败原因。

## 与旧方法的区别和边界

conditional_feedback 已做残差与隐藏表示/时滞/行为交互；history_additive_calibration 已做历史加性项；model_matched 已固定模型身份；均不称未做。本轮固定同一原专家，但同时建立可学习 C 的收益基线，并用较早来源年拟合 r 的 C 条件预测器；后一年才训练冻结基线之外的反馈修正。另拟合不扣除条件预测的 uncentered 对照，除残差定义外全部相同。

这不是新算法或非参数条件独立检验。有限岭模型得到的剩余量不保证独立于 C，更不识别传感器/水过程误差。如果所有读出都是无约束联合线性拟合，残差化可能只是重参数化；这里是分年拟合、先冻结 C-only 收益基线、再单独拟合有界非线性创新特征。只有 on 相对同 C 的 static 及 uncentered 都改善，才支持本固定处理的价值。不能归因于残差化之外未匹配的旧实验差异。

## 完整固定公式

原专家采用原 55 个实际编码输入 v=[z(52),u(3)]：天气仍按原模型压为七日均值，含原土壤特征和根区状态归一化。C_episode=[v_query,v_support,a_support/60,(lag_days-7)/(lag_days+7)]，共 112 维，无站点/年份 ID。保留日期仅生成时滞，未加入实现天气或隐藏通量。

仅 2014 episode 按周期等权估计各列均值 mu 和标准差 sd；sd<1e-6 的列取 1。q=tanh((C-mu)/sd)/sqrt(112)，x=[1,q]/sqrt(2)，故 ||x||<=1。source 2015 和 target 2016 沿用这一变换。

r=(W_observed-W_probe)/原专家SW。仅 2014 拟合 rhat(x)=x A：加权七输出平方误差，ridge=.01，截距不罚。正规方程 (X'WX+.01 diag(0,1,...,1))A=X'Wr；保存全部矩阵、解、残差，要求相对无穷范数残差<=1e-10，正定、有限。此 rhat 只称 C 条件岭预测，不称真条件期望。

2014 冻结 R=max(.001,sqrt(mean(||r||²)))。以同一个 R 构造 f(e)=(e/R)/sqrt(1+||e/R||²)。on 使用 e=r-rhat(x)，uncentered 使用 e=r，均 7 维；不对两种特征单独重标尺度。reverse 使用 -f(r-rhat)。缺观测按缺支持处理；观测等于条件预测 W_probe+SW*rhat 时 e=0，on/reverse 严格等于 static。观测等于原 probe 不一定是条件零创新。

在供体 2015，原归一化收益 raw/SG，T=B*dose/60。先拟合 6×113 的 static 系数 C_s，特征 x，冻结后分别拟合 6×7 的 W_on/W_uncentered。三个拟合均用 smooth SPO+、tau=.05、L2=.01、逐行 L2 半径 .125，年内周期等权，不扫描。on/static、uncentered/static 共享同一冻结 C_s，均保留总归一化输出界 .25。优化 PG∞<=1e-6、最多100000步；不接受零头回退或步数代替收敛。优化器无全局模型有效保证，但固定读出目标为强凸。

五法 raw、static、on、reverse、uncentered。static=raw+SG*T*C_s*x；on 再加 SG*T*W_on*f(e)，reverse 减同项；uncentered 加 SG*T*W_uncentered*f(r)。八档 [0,10,15,20,25,30,40,60]，零剂量恒 0，精确平局选小剂量。502 原参数/bias8/探针/收益 heads 均冻结；这是外置反馈适配，不是原 bias8 梯度 TTA。
