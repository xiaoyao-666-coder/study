# 教师指导的稳健包络 GAM 连续灌溉开发设计

日期：2026-08-06

状态：设计已确认，待实施计划

## 一、研究问题与假设来源

本工作的核心目标是：在站点空间异质性和年份时间非平稳性下，挖掘灌溉响应规律的可迁移边界，并构建兼顾精度和效率的轻量代理模型。GAM、B 样条和稳健包络只是实现该目标的技术手段。

现有嵌套选择 GAM-VC 在 2015--2018 的十五个严格留站点、留年份开发折通过预声明门，但其 2019 连续 SWAP 复算未通过。失败诊断显示：69 个周期中有 24 个周期出现“代理预测连续方案有正优势、SWAP 实际优势为负”；连续推荐比八点选择更远离 SWAP 峰值的 24 个周期全部实际变差。P1 的主要风险是假阳性正灌溉，P15 的主要风险是内部峰值向高灌溉量偏移。

这些 2019 结果只能作为新假设来源，不能用于拟合、参数选择、阈值选择或性能门修改。本轮假设是：跨源站点模型对增量灌溉收益曲线的分歧可以刻画共享规律的失效风险；对该分歧进行最差情形连续优化，可以减少未见站点上的峰值过度外推。

## 二、证据边界

- 开发数据只允许使用 2015--2018。
- 外层验证采用原有五个留出站点乘三个滚动验证年份，共十五折。
- 外层验证周期总数固定为 196：P1 为 38，P2 为 38，P3 为 41，P4 为 39，P15 为 40。
- 2019 的特征和目标均不得被本轮训练、选择、预判定或开发 SWAP 读取。
- 2024 保持封存。
- 任何外层留出站点的目标、预处理统计、惩罚选择信号和站点偏差不得进入对应模型。
- 2019 已被查看并形成假设的事实必须写入所有审计，之后的 2019 结果只能称为复用背景年份上的探索证据。

## 三、正式对照和候选

### 3.1 正式对照

正式对照是当前嵌套伪留站点选择得到的单个四源站点 GAM-VC。每个外层折沿用已冻结的惩罚选择结果，用四个源站点拟合一个模型，对外层留出站点只使用共享项，并在 `[0,60] mm` 上连续求解净收益最大值。

### 3.2 稳健候选

在每个外层折中，保留同一组已选择惩罚，不新增惩罚搜索。对四个源站点依次再留出一个，形成四个三源站点 GAM-VC 子模型：

- 每个子模型独立拟合预处理统计和系数；
- 外层目标站点始终完全排除；
- 被删除的源站点也不参与对应子模型的预处理；
- 预测外层目标站点时，四个子模型均只使用共享项；
- 四个子模型保持原四输出定义和水量平衡约束。

这只是固定、等权的删除一源站点稳健集成，不训练门控网络，不属于 MoE。

## 四、稳健连续目标

对固定状态 `X` 和第 `m` 个子模型，定义相对于零灌溉的净收益增量：

`Delta_m(I, X) = G_m(I, X) - G_m(0, X)`。

稳健目标为四个子模型增量收益的下包络：

`R(I, X) = min_m Delta_m(I, X)`。

正式推荐量为：

`I_robust = argmax_{I in [0,60]} R(I, X)`。

采用相对零灌溉增量而不是绝对收益有两个原因：不同删除站点模型的绝对截距不确定性不应主导灌溉决策；同时 `R(0,X)=0`，当正灌溉未得到所有源站点子模型一致支持时，零灌溉自然成为可竞争的保守解。

四个子模型对 AET、逐日土壤含水量和水量平衡量的预测继续保留。候选的报告值使用四模型算术平均；稳健下包络只用于净收益决策，不改变原输出定义。

## 五、连续求解方法

灌溉量不能从原八个候选值中选择。每个子模型的 `Delta_m(I,X)` 在固定 B 样条区间内是三次多项式。对所有模型样条结点的并集形成共同区间，并在每个区间枚举：

1. 区间左右边界；
2. 每个子模型增量曲线一阶导数的全部区间内实根；
3. 任意两个子模型增量曲线之差的全部区间内实根。

一维连续下包络的区间内最大值只能出现在活动曲线的驻点、活动曲线切换交点或区间边界。因此上述集合是正式完备候选集合。对所有候选计算 `R(I,X)`，选择最大值；并列时选择较小灌溉量。部署分辨率为 `1e-6 mm`。

`0.25 mm` 密网格只用于诊断解析解缺口，不能决定推荐量。解析候选解与密网格最优稳健值的最大允许差为 `0.05` 个净收益单位；超过即执行门失败。

## 六、第一阶段：196 周期开发预判定

第一阶段不运行新的 SWAP，只使用外层验证周期已有的八点 SWAP 标签作为离散参考峰值。对每个周期同时生成原单模型连续解和稳健包络连续解，但不得用目标标签改变解。

必须输出：

- 两种连续推荐量；
- 八点真实参考峰值，收益并列时取较小灌溉量；
- 两种推荐到八点参考峰值的绝对距离；
- 真实零灌溉周期上的正灌溉假阳性；
- 真实正灌溉周期峰值距离；
- 四子模型在连续推荐处的增量收益、均值、最小值、标准差和符号一致性；
- 分折、分站点、分年份结果；
- 四输出的集成均值预测指标和原单模型指标；
- 参数量、拟合时间和单周期求解时间。

第一阶段所有条件必须同时满足：

1. 稳健方案总体平均峰值绝对距离不大于单模型连续方案；
2. 真实正灌溉周期平均峰值绝对距离不大于单模型连续方案；
3. 真实零灌溉周期正灌溉假阳性数量不大于单模型连续方案；
4. 至少 10/15 个外层折的平均峰值绝对距离不差；
5. 全局最大峰值绝对距离不增加；
6. 四输出集成均值的总体宏观综合分数不差于原单模型；
7. 所有解析连续解、密网格诊断、数据隔离和数值有限性审计通过。

这是开发预判定，不是连续实际收益证明。通过只授权在 2015--2018 外层验证周期运行开发 SWAP；失败则停止稳健包络路线，不读取 2019。

## 七、第二阶段：开发年份连续 SWAP

只有第一阶段通过才运行第二阶段。对 196 个外层验证周期分别复算：

- 原单模型连续推荐量；
- 稳健包络连续推荐量。

若两个请求量在 `1e-6 mm` 内相同，只运行一次并在审计中复用同一结果。已有八点正式标签只作为共同参考，不重新生成，不使用目标插值推算连续收益。预计最多新增 392 个正式单候选 SWAP 运行。

数值执行沿用冻结规则：先运行精确请求量，仅在数值失败后依次向下尝试 `0.1、0.2、0.3 mm`，接受首个正常完整结果；不得使用目标值或代理预测选择回退；三档均失败则该阶段失败。逻辑推荐量和实际模拟量必须同时记录。

开发 SWAP 门的正式对照是同折、同周期的原单模型连续解。所有条件必须同时满足：

1. 稳健方案相对单模型方案的总体平均 SWAP 收益差不小于 0；
2. 至少 10/15 个外层折的平均 SWAP 收益不差；
3. 至少 4/5 个站点的平均 SWAP 收益不差；
4. 相对同周期八点真实参考峰值的总体平均遗憾不增加；
5. 全局最大遗憾不增加；
6. 真实零灌溉参考周期的平均 SWAP 收益不差；
7. 真实正灌溉参考周期的平均 SWAP 收益不差；
8. 全部 196 个周期配对完整、数值回退合规且审计通过。

该门是预声明配对工程门，不是显著性检验。通过只授权设计 2019 复用背景年份的探索性协议，不自动进入 2019、MoE、TTA 或最终模型推广。失败则冻结为负结果并停止路线。

## 八、计算规模

第一阶段在现有十五折基础上额外拟合 60 个三源站点线性 GAM-VC，不新增惩罚网格。模型仍是闭式惩罚最小二乘，预计训练和连续求解量显著低于 MLP。

第二阶段仅在第一阶段通过后执行，最多新增 392 个单候选 SWAP 运行，约为此前 69 周期完整粗网格加局部细化候选量的五分之一左右。实际时间仍由 SWAP 单次运行决定。

## 九、审计和停止规则

所有输出必须记录：

- 协议、数据、契约和源开发结果哈希；
- 外层折、源站点、删除源站点和训练行数；
- 外层目标站点及删除源站点的训练和预处理行数均为 0；
- 惩罚值来自现有冻结开发选择，新增超参数搜索为 0；
- 2019 训练、选择、特征和目标读取行数均为 0；
- 2024 读取行数为 0；
- 连续优化、密网格用途、并列规则和候选完备性；
- SWAP 精确请求、实际模拟量、回退尝试顺序和结果；
- 未执行 MoE、TTA、模型推广和自动门禁修改。

任何缺折、缺周期、哈希变化、目标泄漏、未知运行时生成器、非有限数值、解析诊断超差或性能门失败都必须停止，禁止读取下一证据阶段。

## 十、明确不做的事项

- 不根据已查看的 2019 周期选择包络形式、阈值或超参数；
- 不设置针对 P1、P15 的专用规则；
- 不退回从八个灌溉量中直接选最终答案；
- 不使用目标插值替代连续 SWAP；
- 不在本轮加入站点特异完整交互、门控网络、MoE 或 TTA；
- 不把开发年份或 2019 复用年份结果表述为 2024 最终泛化结论。
