# 教师指导的 GAM 峰值位置区间校准设计

日期：2026-08-06

状态：设计已批准，待实施计划

## 一、研究问题与重新开放边界

现有四源 GAM-VC 在 2015--2018 严格开发折上能够形成连续灌溉曲线，但其
2019 复用背景年份 SWAP 资格门未通过。后续的删一源稳健下包络开发虽然降低
了整体平均峰值距离和零灌溉假阳性数，却恶化了正灌溉周期峰值距离、全局最坏
峰值距离和多输出宏观综合指标，因此也在 SWAP 之前停止。

本设计提出新的、独立预注册的研究问题：能否只利用严格开发数据中的交叉拟合
峰值误差，直接校准原四源 GAM-VC 的连续峰值位置，并通过有符号残差区间的中点
形成全周期连续推荐，从而优先降低最坏周期风险，同时不改变原代理模型的多输出
预测？

本设计不重新开放已失败的稳健下包络路线。上一阶段的四源模型和删一源模型仅
作为冻结的预测器及不确定性诊断来源，不代表模型推广。新路线只有在本设计规定
的 2015--2018 第一阶段门禁全部通过后，才允许运行开发年份配对连续 SWAP。

## 二、证据边界

- 开发数据只允许使用 2015--2018。
- 外层验证继续使用五个留出站点乘三个滚动验证年份，共 15 折、196 个周期。
- 外层站点周期计数固定为 P1=38、P2=38、P3=41、P4=39、P15=40。
- 2019 的特征、目标和 SWAP 结果不得用于训练、特征标准化、超参数选择、残差
  分位数、门禁或结果预判；读取行数必须为 0。
- 2024 保持封存，读取行数必须为 0。
- 外层目标站点的行、目标、预处理统计和站点项不得进入对应折的基础模型、内层
  峰值样本、校准器或区间计算。
- 2019 已被查看并形成研究假设的事实必须保留在审计中；后续即使获得开发门
  通过，也不能把 2019 作为独立最终泛化证据。

## 三、正式对照与候选

### 3.1 正式对照

正式对照为每个外层折现有的四源 GAM-VC 连续峰值。模型沿用已冻结的外层折
惩罚选择结果，对留出站点只使用共享项，并在 `[0,60] mm` 上通过分段三次样条
驻点和区间边界精确求解。原八个灌溉量只提供 SWAP 标签和离散参考峰值，不作为
最终连续答案。

### 3.2 正式候选

正式候选为经过严格嵌套峰值位置校准后的连续量。校准器预测：

`delta = true_fixed_grid_peak_mm - raw_gam_peak_mm`。

其中 `true_fixed_grid_peak_mm` 是同一周期八点 SWAP 标签中的最大净收益灌溉量；
收益并列时选择较小灌溉量。该目标只用于严格训练折中的校准器拟合和外层验证
后的指标计算，不能传入原 GAM 连续求解过程。

校准候选不重新拟合 AET、VWC、水量平衡或净收益代理输出。原四源 GAM 的所有
多输出预测保持不变，仅修正连续峰值位置。

## 四、目标无关的校准特征

每个周期的正式特征只由模型输出和决策时状态生成，不含任何 SWAP 目标、峰值
误差或外层验证标签：

1. 原四源 GAM 连续峰值 `raw_peak_mm`。
2. 原峰值是否位于 0 mm 或 60 mm 边界。
3. 原峰值处相对零灌溉的预测净收益 margin。
4. 原峰值处曲率绝对值；边界解使用单侧二阶导数并记录边界标志。
5. 删一源模型各自连续峰值的均值、中位数、标准差、范围、最小值和最大值。
6. 原四源峰值与删一源峰值中位数之差。
7. 在原四源峰值处，各删一源模型增量收益的均值、标准差和正值比例。

内层拟合阶段可能只有三个可用源站点，因此删一源诊断模型数量可为三个；正式
特征只使用均值、中位数、标准差、范围和比例等与模型数量无关的聚合量。缺少、
重复、非有限或目标污染的特征立即停止。

不把完整 51 维状态直接送入校准器。该限制用于控制 196 个开发周期下的模型
容量，并使校准器只回答“现有连续峰值应移动多少”，而不是重新学习完整代理
模型。

## 五、严格嵌套样本生成

### 5.1 外层折

外层折保持原协议：目标站点完全留出，验证年份依次为 2016、2017、2018；对应
训练年份分别为 `[2015]`、`[2015,2016]`、`[2015,2016,2017]`。

每个外层折优先复用上一阶段完整服务器输出中保存的四源基线和四个删一源模型
系数。复用前必须核验协议、数据、源开发结果、逐折完成标记和模型 NPZ 哈希。
任一哈希缺失或变化时，不得静默复用；只能在同一冻结外层训练行上重新拟合并
在审计中记录原因和新哈希。

### 5.2 内层源站点-年份留出

校准训练样本只能来自外层训练范围。对外层训练中的每个源站点和每个可用年份
建立内层留出单元：

- 留出该源站点在该年份的全部周期作为内层验证单元；
- 模型训练只使用其余源站点，年份不得晚于该内层验证年份；
- 同年其他源站点数据允许使用，因为在外层验证发生前这些源站点历史已经可用；
- 外层目标站点始终完全排除；
- 对内层留出站点只使用共享项预测。

内层基线使用其余源站点拟合；对应删一源诊断模型再依次删除一个可用源站点。
因此内层和外层采用相同的“基础连续峰值加删除一源分歧诊断”接口，但不要求
诊断模型数量相同。

### 5.3 校准器交叉验证

所有内层留出预测组成目标无关特征、原峰值和八点参考峰值表。校准器的候选
参数选择再次按 `(site_id, year)` 分组留出，确保同一站点年份的周期不会同时
进入校准器拟合和验证。

参数选定后，使用该参数重新进行分组交叉预测，生成有符号校准残差；这些交叉
预测残差用于分位数区间。最终校准器才在全部内层留出样本上拟合，并应用于外层
目标站点验证周期。

## 六、最坏风险加权的低容量校准器

校准器为带截距的线性加权岭回归。所有连续特征只在当前拟合子集上标准化；截距
不惩罚。训练目标为：

`sum_i w_i * (delta_i - x_i beta)^2 + lambda * ||beta||_2^2`。

在每个校准器拟合子集中，先按原 GAM 峰值到八点参考峰值的绝对距离计算第 80
百分位。高于或等于该分位数的训练样本权重为 `1 + gamma`，其余样本权重为 1。
验证单元的标签不能参与权重阈值计算。

预声明候选网格固定为：

- `gamma in [0.0, 2.0, 5.0]`
- `lambda in [0.1, 1.0, 10.0]`

候选参数按以下字典序选择：

1. 分组验证全局最大绝对峰值误差最小；
2. 正灌溉参考周期平均绝对峰值误差最小；
3. 总体平均绝对峰值误差最小；
4. 完全并列时优先更大的 `lambda`，随后优先更小的 `gamma`。

不得增加站点专用参数、年份专用参数、P1/P15 专用规则或看到外层结果后扩大
网格。

## 七、有符号残差区间与最终连续推荐

使用选定参数得到的分组交叉预测，计算：

`residual = true_fixed_grid_peak_mm - corrected_point_peak_mm`。

在当前外层折的内层交叉预测残差上，按固定有限样本经验分位数方法计算 `q05`
和 `q95`。不按外层目标站点、年份或结果事后分组。正式点预测和区间为：

- `point_peak = raw_peak + predicted_delta`
- `lower = point_peak + q05`
- `upper = point_peak + q95`

点预测、下界和上界分别裁剪到 `[0,60] mm`。若裁剪后 `lower > upper`、出现非
有限数或区间宽度为负，立即失败。最终连续推荐固定为：

`calibrated_peak_mm = (lower + upper) / 2`。

最终结果保留 `1e-6 mm` 分辨率；同值时选择较小灌溉量。不得取整、吸附到八点
候选或按区间宽度触发离散回退。区间宽度只用于风险和覆盖率审计。

## 八、第一阶段：196 周期峰值校准预判定

第一阶段不运行新 SWAP。正式对照为原四源 GAM 连续峰值，正式候选为校准区间
中点。所有条件必须同时满足，容差固定为 0：

1. 候选全局最大峰值绝对距离不大于对照。
2. 候选峰值绝对距离第 95 百分位不大于对照。
3. 真实正灌溉参考周期的平均峰值绝对距离不大于对照。
4. 全体周期平均峰值绝对距离不大于对照。
5. 真实零灌溉参考周期的正灌溉假阳性数量不大于对照；正灌溉定义为大于
   `1e-6 mm`。
6. 至少 10/15 个外层折的平均峰值绝对距离不差。
7. `[lower, upper]` 对八点参考峰值的总体经验覆盖率至少为 0.90。
8. 原模型多输出预测及其哈希完全不变，全部折、周期、内层分组、参数选择、
   区间、数据隔离和数值有限性审计通过。

该门是预声明工程开发门，不是显著性检验。任何一项失败即冻结校准路线，不运行
开发年份 SWAP，也不读取 2019。

## 九、第二阶段：2015--2018 配对连续 SWAP

只有第一阶段全部通过，才为 196 个外层验证周期分别复算：

- 原四源 GAM 连续推荐量；
- 峰值区间校准连续推荐量。

若两个逻辑请求量在 `1e-6 mm` 内相同，只运行一次并在配对审计中复用。已有八点
SWAP 标签只作为共同参考，不重新生成，不使用目标插值替代连续 SWAP。预计最多
新增 392 个正式单候选 SWAP 运行。

数值回退沿用冻结规则：先运行精确请求量，仅在数值失败后依次尝试向下偏移
`0.1、0.2、0.3 mm`，接受首个正常完整结果；不得根据目标值、代理预测或收益
选择回退。三档均失败则阶段失败。逻辑请求量和实际模拟量必须同时保留。

第二阶段所有条件必须同时满足：

1. 候选相对对照的总体平均 SWAP 收益差不小于 0。
2. 至少 10/15 个外层折平均 SWAP 收益不差。
3. 至少 4/5 个站点平均 SWAP 收益不差。
4. 相对同周期八点参考峰值的总体平均 regret 不增加。
5. 全局最大 regret 不增加。
6. regret 最差 10% 周期的平均值不增加。
7. 真实零灌溉参考周期和真实正灌溉参考周期的平均 SWAP 收益均不差。
8. 全部 196 周期配对完整，数值回退、生成器哈希、目标隔离和结果有限性审计
   全部通过。

第二阶段通过只授权另行设计 2019 复用背景年份探索协议，不自动读取 2019、不
进入 MoE/TTA、不最终重拟合或推广模型。失败即冻结为负结果。

## 十一、失败处理与断点续跑

- 缺折、缺周期、重复键、模型或输入哈希变化、目标泄漏、非有限数、区间反转、
  越界结果、内层分组不足或门禁失败均立即停止。
- 每个外层折原子写入周期表、校准模型、参数选择、交叉残差和完成标记；只有完成
  标记与全部文件哈希匹配才允许 `--resume` 跳过。
- 同一冻结协议中断后可使用原输出目录 `--resume`；协议、特征、网格或门禁变化
  必须使用新协议编号和新输出目录。
- 失败目录、部分折和负结果包均保留，不删除、不覆盖。

## 十二、测试要求

实现计划必须覆盖：

- 协议字段逐项校验及 2019/2024 越界拒绝。
- 内层源站点-年份留出不泄漏外层目标站点或未来年份。
- 特征构建不访问目标列，内层三个和外层四个诊断模型使用相同聚合接口。
- 加权岭回归、截距不惩罚、仅训练子集标准化和参数字典序选择。
- 有符号经验分位数、边界裁剪、区间中点和 `1e-6 mm` 连续精度。
- 合成最坏误差样本中，高风险加权候选优先降低最大误差。
- 八项第一阶段门分别单独失败时总门失败。
- 第二阶段配对、相同请求复用、三档数值回退和最差 10% regret 门。
- 完成标记、哈希变化和 `--resume` 拒绝路径。

本地只运行单元测试、语法检查、合成数据测试和干净净包验证。正式 15 折和任何
SWAP 均在服务器运行。

## 十三、明确不做的事项

- 不使用 2019/2024 训练或选择校准器。
- 不加入 P1、P15 或年份专用规则。
- 不把完整 51 维状态直接输入校准器。
- 不重新训练神经网络、门控网络、MoE 或 TTA。
- 不吸附、舍入或回退到八点 fixed-list 作为最终推荐。
- 不修改已经失败的 GAM-VC、稳健下包络门禁或其正式结果。
- 不在第一阶段通过前编写或启动正式开发 SWAP 运行。
- 不把开发年份结果或未来 2019 探索结果表述为 2024 最终泛化结论。
