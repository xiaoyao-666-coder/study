# 分层 GAM 连续 SWAP 数值回退 v2 设计

日期：2026-08-05

## 一、问题与证据

分层 GAM 已冻结 69 条 2019 年连续推荐，推荐阶段门禁全部通过。首次正式 SWAP 复算在 `P2/2019-05-27` 的全局粗搜索中失败：请求 `25.0 mm` 未正常完成，原单值回退 `24.8 mm` 也未完成。独立干净工作区复现排除了阶段工作区污染；诊断性顺序回退表明 `24.7 mm` 能完整运行并出现 `Swap normal completion!`。

该现象属于 SWAP 数值稳定性问题，不构成 GAM 预测误差证据。诊断是在观察失败后完成的，因此不能把 `24.7 mm` 结果直接填入 v1 正式结果，必须先冻结统一规则并重新执行正式复算。

## 二、采用方案

建立 `teacher-guided-hierarchical-gam-continuous-swap-qualification-v2` 协议。保留原 69 条推荐、五个严格留站点模型、连续优化方法、固定八候选对照、自适应 SWAP 参考和四项性能门，只更新 SWAP 数值失败后的确定性回退规则。

v1 失败目录永久保留为审计证据。v2 使用全新的输出目录，不读取或复用 v1 已通过阶段，不把诊断目录作为正式输入。

## 三、统一数值回退规则

对每个大于 `0 mm` 的请求灌溉量 `I`：

1. 首先运行精确请求量 `I`。
2. 只有精确请求未出现 `Swap normal completion!` 时，才依次尝试 `I-0.1`、`I-0.2`、`I-0.3 mm`。
3. 对低于 `0 mm` 的回退值截断为 `0 mm`，去除重复值，且不允许回退值大于或等于原请求量。
4. 使用第一个正常完成且通过输出完整性检查的回退结果；禁止根据收益、遗憾或代理预测选择回退值。
5. 三次回退均失败时，该候选和所在正式阶段失败；不得继续追加 `0.4 mm` 或更大偏移。
6. `0 mm` 不设置回退。

最大允许数值偏移固定为 `0.3 mm`。该规则同时应用于全局粗搜索、局部细化、连续推荐、固定八候选和自适应参考，不允许按站点、日期、模型角色或候选类型设置例外。

## 四、结果语义与审计

每个候选必须同时记录：

- `ir` 和 `requested_ir_mm`：逻辑请求量，参与候选集合、配对和门禁定义。
- `simulated_ir_mm`：SWAP 实际运行量。
- `numerical_irrigation_fallback`：是否使用回退。
- `numerical_irrigation_fallback_attempt_count`：已尝试回退次数。
- `numerical_irrigation_fallback_attempted_values_mm`：按顺序记录的回退值。
- `numerical_irrigation_fallback_delta_mm`：实际运行量减请求量。
- 原请求失败类型、错误文本和成功回退日志路径。

使用回退的结果只能表述为“请求量的数值回退结果”，不得表述为精确请求量的 SWAP 结果。正式阶段审计必须汇总回退总数、涉及站点和日期、最大绝对偏移、第二级和第三级回退次数，以及回退耗尽失败数。

正常完成标记只是第一道条件。候选还必须生成完整七天输出，关键指标为有限数，固定 0--100 cm 水量平衡残差绝对值不超过既有 `0.5 mm` 门槛。

## 五、数据与模型边界

- 69 条连续推荐及其清单哈希保持不变，不重新训练、重新选惩罚或修改推荐量。
- 2019 继续是已复用的背景验证年份，不能表述为独立最终测试。
- 2024 保持封存，不读取任何特征或目标。
- v2 SWAP 阶段不得训练代理模型、MoE 或 TTA，不得修改已冻结推荐。
- 数值回退不使用目标收益做选择，因此不构成新的模型调参。

## 六、正式执行与输出隔离

正式输出目录固定为：

`site_general_surrogate_eval/gefs_teacher_guided_hierarchical_gam_continuous_swap_qualification_v2`

必须从第一个周期开始完整执行 69 个周期。不得使用 v1 的 `--resume` 目录，不复制 v1 的 `stage_audit.json`、`swap_candidates.csv` 或分支结果。中断后只允许在 v2 自身目录内按相同协议断点续跑。

原四项配对无伤害工程门保持不变：总体平均连续 SWAP 收益不差于同模型八候选决策、至少 4/5 站点平均收益不差、至少 35/69 周期收益不差、全局最大自适应参考遗憾不增加。任何数值执行门失败都先于性能门，禁止用部分周期计算正式性能结论。

## 七、验证要求

实施前必须增加回归测试，覆盖：

- 默认旧调用仍可使用单值 `-0.2 mm` 回退，避免影响其他既有实验。
- GAM v2 从协议读取并生成 `-0.1、-0.2、-0.3 mm` 顺序回退。
- 第一级失败、第二级成功时停止继续尝试。
- 第三级成功时正确记录请求量、实际量、次数和偏移。
- 三次全部失败时正式阶段失败。
- v2 拒绝 v1 协议、旧输出目录和不一致的回退参数。
- 推荐清单及其哈希在 v2 启动前保持不变。

正式包只在本地运行单元测试、语法检查和净包测试；正式 69 周期 SWAP 仅在服务器运行。
